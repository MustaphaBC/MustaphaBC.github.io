# Mustapha Ben-Cheikh — CV site

A responsive, static CV and project portfolio for [MustaphaBC](https://github.com/MustaphaBC), published at [mustaphabc.github.io](https://mustaphabc.github.io/).

## Run locally

Open index.html in a browser, or serve the folder with any static file server.

## Publish

The site is designed for GitHub Pages from the main branch and repository root. The page links to a one-page A4 CV PDF at output/pdf/Mustapha_Ben-Cheikh_CV.pdf. Project links in the PDF open the corresponding repositories.

## Stack

The site uses plain HTML and CSS. It has no build step, package install, remote font, or external image dependency.
